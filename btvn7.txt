Phần 2
3. Local (Ctrl+S) > Auto Sync (Google Drive for desktop) > Cloud (Google Drive).
Sync: thư mục CampusPay (Plan, Code, Docs, Slide).
Không Sync: game, phim, file cá nhân.

4. file chưa xong hiện biểu tượng 2 mũi tên xoay, xong mới có tích xanh. gập máy thì sync bị dừng, file chưa lên Cloud. cách làm: chờ tích xanh rồi mới gập máy.
